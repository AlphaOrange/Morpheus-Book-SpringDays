# Spring Days

A book for the interactive story engine _Morpheus_.

This interactive book focusses on young romance, enabling you to play any one of the students in the game, discovering places in Honeybrook and go on romantic adventure. There is no inherent story or mystery, just conversation and a lot of sparks.
